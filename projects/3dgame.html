3D Browser Game

Three.js JavaScript WebGL Next.js

Overview

An immersive 3D browser game built with Three.js and WebGL. This project explores 3D graphics programming, including scene management, lighting, textures, and real-time rendering. A significant step up from 2D, showcasing the power of modern browser capabilities for interactive 3D experiences.

Technical Details

3D scene management with Three.js, real-time WebGL rendering, dynamic lighting and texture mapping, camera controls and user interaction, and integration within the Next.js Sip & Grow website.
