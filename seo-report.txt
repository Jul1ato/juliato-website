  CRITICAL ISSUES (High Impact)

1. IMAGES ARE MASSIVELY UNOPTIMIZED
-------------------------------------------------------------------------------
   Your images total 14+ MB of uncompressed PNGs. This crushes Core Web Vitals
   (LCP, FCP) and will directly hurt your Google rankings.

   File                          Size        Problem
   -------------------------------------------------------
   Screenshot4.png (Sip & Grow)  7.3 MB      Extremely heavy
   Screenshot2.png (3D Game)     2.4 MB      Very heavy
   image2.png (unused)           1.9 MB      Not referenced anywhere
   image1.png (avatar/OG)        1.6 MB      Heavy for an avatar
   Screenshot1.png (CryptoHub)   1.1 MB      Heavy

   FIX: Convert all images to WebP/AVIF format. You already have optimized
   versions in the screenshots/ directory (60KB-160KB) that are never used
   in any HTML file. Use those, or compress the originals to <200KB each.
   Delete the unused image2.png.


2. NO loading="lazy", NO width/height ON IMAGES
-------------------------------------------------------------------------------
   Every <img> tag is missing width, height, and loading="lazy" attributes.
   This causes:
   - Layout shift (CLS) — hurts Core Web Vitals
   - All images load at once — slower initial page load

   FIX: Add width, height, and loading="lazy" to all images below the fold.
   Add fetchpriority="high" to the hero/above-fold image.


3. NO FAVICON OR WEB APP MANIFEST
-------------------------------------------------------------------------------
   No favicon.ico, no apple-touch-icon, no manifest.json or site.webmanifest.
   This affects:
   - Browser tab appearance (looks unprofessional)
   - PWA installability
   - Google's ability to display your site icon in search results

   FIX: Create a favicon set (16x16, 32x32, 180x180 apple-touch-icon,
   192x192, 512x512) and a site.webmanifest file.

5. admin.html IS PUBLICLY INDEXABLE
-------------------------------------------------------------------------------
   Your admin.html page has no noindex tag and isn't blocked in robots.txt.
   Search engines can and will index it.

   FIX: Add <meta name="robots" content="noindex, nofollow"> to admin.html
   and add Disallow: /admin to robots.txt.

14. NO llms.txt FILE
-------------------------------------------------------------------------------
    The llms.txt standard (llmstxt.org) tells AI models what your site is
    about. You're returning a 404. This is increasingly important as
    AI-powered search (Google AI Overviews, ChatGPT search, Perplexity)
    becomes mainstream.

    FIX: Create a /llms.txt file with structured info about you, your
    projects, your skills, and your contact links. Example:

      # juliato.dev

      > A developer portfolio by juliato, specializing in web development,
      > 3D graphics, and AI projects.

      ## About
      juliato is a developer focused on building modern web applications,
      interactive 3D experiences, and AI-powered tools. Based in Malta.

      ## Projects
      - CryptoHub Malta: A comprehensive crypto community website built
        with Next.js, React, and TypeScript
      - Sip & Grow: A business website with integrated 2D and 3D browser
        games
      - 2D Browser Game: A JavaScript/Canvas platformer game
      - 3D Browser Game: A Three.js/WebGL interactive 3D experience

      ## Skills
      Frontend: HTML, CSS, JavaScript, TypeScript, React, Next.js, Three.js
      Backend: Node.js, Python
      AI: Machine Learning, Automation

      ## Contact
      Website: https://juliato.dev
      GitHub: https://github.com/Jul1ato
      LinkedIn: https://www.linkedin.com/in/juliato/
